# BMad Editorial Review - Structure

## When to Use
Use when a document has the right raw material but the organization, flow, or section boundaries are weak.

## Goal
Make the document structurally coherent and easier for downstream humans/agents to use.

## Procedure
1. Review the document's section order and hierarchy.
2. Identify duplication, misplaced content, or missing transitions.
3. Reorganize while preserving meaning and evidence.
4. Flag content gaps rather than inventing filler.
5. Hand back to prose review if the main issue becomes wording quality.

## Completion Output
Report the structural changes made and any remaining content gaps.

# BMad Editorial Review - Prose

## When to Use
Use after drafting when wording quality needs improvement but the structure is already mostly correct.

## Goal
Polish prose without distorting technical meaning or product intent.

## Procedure
1. Review the document for awkward, vague, or misleading wording.
2. Improve clarity and readability while preserving meaning.
3. Flag statements that still lack evidence or specificity.
4. Keep edits auditable and proportional.
5. Hand off to structural review if organization is the deeper issue.

## Completion Output
Report the main prose improvements made and any content that still needs substantive clarification.

# BMad Agent Tech Writer

## When to Use
Use when a technical document, structured explanation, or diagram needs to be produced or refined.

## Goal
Create technical writing that is clear, grounded, and useful to downstream BMad workflows.

## Procedure
1. Identify audience, purpose, and artifact destination.
2. Gather source truth from repo, artifacts, and explicit decisions.
3. Write or refine the document in a structured form.
4. Call out assumptions and unresolved questions.
5. Prefer canonical project artifacts over random standalone docs when possible.

## Completion Output
Report document purpose, source truth used, unresolved questions, and where the document now lives.
